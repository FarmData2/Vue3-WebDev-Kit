# Commit Attribution Trailers

If you were assisted by another person or an AI tool in the creation of the content in a commit you must include an commit trailer giving attribution. There are three commonly used commit trailers to make different types of attribution. Use your best judgment in selecting the appropriate trailers.

## Human Coauthors

If you worked with another human on the commit, add a `Co-authored-by` commit trailer when you make your commit as follows.

```bash
git commit -m "<your commit message>" \
  --trailer "Co-authored-by: First Last <first@example.com>"
```

If you had more than one coauthor, add a trailer for each one as follows.

```bash
git commit -m "<your commit message>" \
  --trailer "Co-authored-by: First Last <first@example.com>" \
  --trailer "Co-authored-by: First2 Last2 <first2@example.com>" \
  --trailer "Co-authored-by: First3 Last3 <first3@example.com>"
```

Notes:

- The [Coauthors Generator](https://coauthors.me/generator) utility provides a convenient way to generate a Co-authored-by trailer by using your coauthor's GitHub id.

## AI Assisted Content

If the commit contains a combination of code created by you and by AI, add an `Assisted-by` trailer when you make your commit as follows.

```bash
git commit -m "<your commit message>" \
  --trailer "Assisted-by: Model, version"
```

Notes:

- Examples:
  - `Assisted-by: GPT, 4.5`
  - `Assisted-by: Claude, 3.7 Sonnet`
- This trailer is generally used when you ask AI to generate full functions or blocks of code, but then add code of your own, or edit and adapt the generated code.
- This trailer is generally not necessary when you use AI autocomplete (_tab completion_) for fragments of code, under the assumption that you will review each of the AI suggestions carefully.

## Human Coauthors and AI Assisted Content

If you were assisted by both a human coauthor and an AI tool, add both a `Co-authored-by` and an `Assisted-by` trailer when you make your commit as follows.

```bash
git commit -m "<your commit message>" \
  --trailer "Co-authored-by: First Name <first@example.com>" \
  --trailer "Assisted-by: Model, version"
```

## AI Generated Content

If the commit contains only code generated by AI, add a `Generated-by` trailer when you make your commit as follows.

```bash
git commit -m "<your commit message>" \
  --trailer "Generated-by: Model, version"
```

Notes:

- This trailer is required when you use a _planning mode_ and _AI agents_ to autonomously generate significant amounts of code. Extensive prompting or collaboration with the AI in the creation of a plan does not change the necessity of a `Generated-by` trailer.
- If you plan to use an AI to generate significant amounts of code that you plan to edit and adapt, use separate commits for the generated code (with a `Generated-by` trailer) and your own modifications.
- A `Generated-by` trailer is, by definition, incompatible with both the `Co-authored-by` and the `Assisted-by` trailers, and should never be combined with them.

## Adding a Forgotten Attribution

If you forget to add an attribution commit trailer for a coauthor or to acknowledge AI use, you can add one using an empty commit as follows:

```bash
git commit --allow-empty \
  -m "adding trailers`
  --trailer "Co-authored-by: First Name <first@example.com>"
```
